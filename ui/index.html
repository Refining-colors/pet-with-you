暂无未忽略的错误。

运行模式

默认纯桌宠，独立运行。可配置自有 API 进行聊天、碎碎念和密钥额度查询。打开连接模式才显示客户端任务联动和账户登录相关设置；切换立即保存。

启动与位置

开机启动使用当前用户的 Startup 目录。移动项目后请手动启动一次以更新启动路径。

开启后立即停止自主移动，随机动作原地播放；仍可手动拖动和抛掷，吸附设置继续生效。此开关自动保存。

靠近边缘约 36 像素时吸附，拖动可脱离。为完整动画留出底部余量，静止时双脚略微悬空。GPT 窗口识别仅限 Windows 桌面客户端。

聊天与碎碎念

纯桌宠使用自有 API；连接 GPT 后仍可使用自有 API。服务来源同时用于聊天和碎碎念，不影响任务联动。

自有 API 配置

填写 OpenAI 兼容接口后，纯桌宠也能聊天、自动碎碎念，并可在额度查询中选择 API 密钥。API 地址可填服务商的 v1 地址，也可直接填完整的 /chat/completions 地址。

列表中的配置可重复使用，密钥使用系统加密保存。清除当前配置不删除列表；删除列表项不影响正在使用的配置。

碎碎念设置

支持流式输出的服务会尽早显示正文；不能缩短模型开始输出前的等待。若接口不支持流式请求，可关闭此项。

自动碎碎念

与“自动碎碎念”模块共用设置。使用当前聊天服务；忙碌或已有回复时跳过，实际生成会消耗模型用量。

本次运行的碎碎念记录

每只宠物单独记住说过的话，切换模式仍保留；退出桌宠后清空，不写入磁盘。最近记录会用于下一次生成，重复句子会跳过，不自动重试。

    自动碎碎念

    启动后先等待一个完整间隔。每次按概率决定是否生成一句；0% 不触发，100% 每次触发。任务反馈、聊天、拖动或已有回复时跳过，不打断阅读。使用当前聊天服务，实际生成会消耗模型用量；未命中概率不调用模型。

    回复气泡

    聊天与碎碎念共用停留设置。气泡支持选中文字后 Ctrl+C 复制，右上角 × 关闭；任务反馈优先显示，同一只宠物的消息不会叠在一起。

    “下一次信息前不消失”：新回复、任务反馈或查询信息会替换旧回复。“永久”：最新回复保留到手动关闭，任务反馈显示期间暂时隐藏，结束后恢复；新回复更新原气泡。永久指本次桌宠运行期间。

    密钥 / 代理额度

    只向你填写并保存的查询接口发送所选密钥，查询失败不会自动尝试其他网站。

    设置密钥 / 代理查询

    查询接口格式（按服务商说明填写）

    普通接口支持 HTTPS GET JSON；CRS 地址会自动使用其统计接口，显示费用、请求、Token 和限额。只有余额没有总额度时，只显示金额，不编造百分比。

    同名配置会更新。清除当前配置保留列表；删除列表项不影响当前配置。手动密钥加密保存，其他密钥来源在查询时读取。

    气泡显示字体

    额度查询默认使用宋体；基础反馈、聊天和碎碎念可独立选择字体。支持系统字体和导入 TTF / OTF，任务卡标题保留原生界面字体。

    窗口与点击

    按前台全屏窗口所在屏幕隐藏；退出全屏后恢复。例外识别 Codex / ChatGPT 桌面应用，浏览器里的 GPT 页面不在例外内。

    桌上的伙伴

    拖动滑条或输入 180–900 的尺寸，数值同步更新。关闭设置时自动保存并应用。

    播放与互动

    右键宠物 → 动作 → 吃什么 / 玩耍等分类，即可点播。一个节目结束后会继续随机选择。

    分类权重设为 0 可从随机播放中排除，仍可右键点播。

    高级配置

    高级配置与额外宠物

    额外宠物放在配置目录的 pet/ 下，使用原项目的 pet pack 格式。托盘菜单可以打开该目录。保存会重建宠物窗口。

    错误日志

    记录聊天、碎碎念、额度查询及设置操作的错误，便于导出反馈。不包含密钥、完整网址、聊天内容或服务商原始响应；相同错误一分钟内合并，最多保留约 768 KB，满后自动淘汰旧记录。

    这里只管理安全错误日志；旧版 desktop.log 启动输出不参与导出或清理。

    默认开启，适合中转 / 自有 API 用户。停止自动读取账户信息，已识别的同类历史错误隐藏，后续同类错误不提醒、不写入日志；仍可手动查询。自有 API、代理额度、任务联动和其他错误照常记录。关闭可重新查看已保存的同类历史错误。

      任务动画与通知
