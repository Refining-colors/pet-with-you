## 0.1.0-alpha.1 历史检查

检查日期：2026-09-28。范围是本机 Windows 的源码、现有 Git 历史、打包输出与隔离测试；不是第三方安全审计，也不保证所有机器或服务商兼容。

## 本轮发现并修复

- 手动查询成功后，前端残留旧变量导致误报失败；已修复并验证气泡显示成功内容。
- 缺少真正的 Windows 安装配置、可选桌面快捷方式及 EXE 图标；补齐安装器和路径自动定位。
- 打包后的 Hooks 原先仍依赖外部 Node.js；改用安装包内置运行环境。
- 屏幕缩放探测的命令参数未被运行入口识别，导致首次启动等待超时；补齐识别并绕过正常应用的单实例锁。
- 安装脚本在构建卸载器时重复定义安装页面；分开编译，保持构建警告视为错误。
- 升级时避免执行清理连接配置的完整卸载逻辑；普通卸载保留用户数据。
- 宠物渲染器开启沙箱，设置和宠物窗口限制页面跳转及弹出新窗口。
- 自有 API 接受 IPv6 本地回环地址，继续拒绝远程明文 HTTP。

## 验证范围

- 69 项单元测试与 Electron 桌面界面验证，包括额度成功内容、拖动、模块排序、自动保存、动画、聊天、日志及窗口隔离。
- 在全新临时源码目录执行安装脚本，重新安装依赖并通过必要环境检查。
- 源码快捷方式使用含空格、中文、单引号的迁移目录，核对目标、参数、工作目录和图标。
- 安装包在临时目录实际安装/卸载，覆盖桌面快捷方式的两种选择和开始菜单入口；安装后的应用在没有外部 Node.js 的 PATH 中运行。
- 待提交文件与已有 Git 历史检查常见密钥、私有配置、私钥和个人绝对路径；文档配图人工确认使用演示数据。测试中的假密钥与示例地址不是真实凭据。
- 依赖审计与文档本地链接检查；安装包内容排除源码 Git 信息、个人数据、测试日志和依赖缓存。

实际命令与重新验证方式见 [打包说明](PACKAGING.md)。校验值随本地安装包放在 `dist/SHA256SUMS.txt`，重新构建后需重新生成，不把旧校验值用于新文件。
