首次提供可直接安装的 Windows x64 公开预览版。下载 **pet-with-you-0.1.0-alpha.5-x64-setup.exe**，双击选择安装目录和桌面快捷方式，完成后从 **pet-with-u** 启动。

纯桌宠无需另装 Node.js、Git 或 Codex CLI，也无需密钥。聊天、自有 API、额度与 Codex 联动均可选配置。**Source code (zip)** 是源码，普通用户请选择上面的 EXE。

### 窗口与托盘更新

- 窗口设置改为四选一，原有冲突组合自动迁移。
- “GPT置顶，其余全屏隐藏”：仅客户端在前台时置顶，其他普通窗口下不置顶，其他全屏应用下隐藏。
- 单击托盘即可立即显示并临时置顶 8 秒，随后恢复原规则；双击打开设置。
- 安装与使用手册统一以 EXE 安装版为普通用户入口。

### 本版内容

- 106 段角色动画、随机播放与手动点播，区分原地动作和实际跑动。
- 自有 API 聊天、流式碎碎念、自动碎碎念，以及配置保存/载入。
- Codex 任务、多任务卡片、账户额度与服务商查询；默认关闭连接与自动查询。
- 统一设置、关闭设置自动保存、尺寸/字体自定义、日志与快捷方式创建。
- Codex withu 可选联合启动器，更新图标与 Unicode 路径支持；无需常驻启动检测。

### 安装与升级

支持 Windows 10/11 x64。安装仅针对当前用户；安装包自带运行环境，不含维护者的密钥、账户、个人设置、日志或视频实验素材，也不附带第三方字体。下载旁边的 `INSTALL.txt` 可查看简明安装说明，`SHA256SUMS.txt` 可核对安装程序。

已有用户请先退出桌宠，再安装到原目录；设置独立保存，卸载默认保留用户数据。目前没有自动更新。安装包尚未签名，Windows 可能提示未知发布者，请核对仓库和校验值。此版仍标记为预览版，不代表所有系统、Codex 安装渠道或 API 服务商均已验证。
