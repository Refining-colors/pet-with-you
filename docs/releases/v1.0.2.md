# pet-with-you 1.0.2

Windows 10/11 x64 桌宠。普通用户下载 **pet-with-you-1.0.2-x64-setup.exe**，无需另装 Node.js 或下载源码。

## 本次更新

- 修复 Hooks 将脚本路径作为文字带进无关 Codex 对话的问题；桌宠关闭时保持静默。
- 修复多个对话并行时出现无名任务、已结束任务重新变成进行中的问题；内部子任务不再作为独立对话计数。
- 补齐任务名称，在“另有 X 个任务”前增加分隔线。
- 换显示器后启动时重新检测缩放，避免宠物和菜单沿用旧比例；托盘改用多尺寸方形图标，避免角色变形。
- 移除与 Codex 重复的 Windows 任务通知，保留桌宠动画和气泡反馈。

## 安装与升级

1. 从托盘正常退出旧桌宠，再运行安装程序覆盖安装，无需先卸载；个人设置、密钥和自定义角色保留。
2. 启用 GPT 连接的用户，升级后在桌宠控制台重新配置/检查连接，并在 Codex 客户端重新授权更新后的 Hooks。入口未刷新时先切换对话，必要时等任务结束后重启客户端。
3. 正常为当前安装目录登记 9 项 Hooks；如另有指向旧安装/开发目录的重复项，可在客户端核对路径后禁用旧项，勿删除其他工具的 Hooks。
4. 下载页附 SHA256SUMS.txt 和 INSTALL.txt。安装包尚未签名，Windows 可能显示未知发布者提示。

纯桌宠仍可独立使用；本次更新不增加模型调用。运行中更换主屏缩放后，请重启桌宠以应用整体界面比例。
