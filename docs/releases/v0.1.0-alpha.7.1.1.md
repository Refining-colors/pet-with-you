# pet-with-you 0.1.0-alpha.7.1.1

本次修正安装界面、更新后的快捷方式图标，以及 GPT 连接设置的反馈。

## 下载安装

下载本页 Assets 中的 **pet-with-you-0.1.0-alpha.7.1.1-x64-setup.exe**，双击安装。纯桌宠无需另装 Node.js、Git 或 Codex CLI。`Source code (zip)` 是源码，不是安装程序。

已安装旧版的用户：先从托盘退出桌宠，再运行新版安装程序，沿用原安装目录即可覆盖升级，无需先卸载；保留个人设置、密钥和位置。

## 本次更新

- 欢迎页和完成页正确显示可爱小女仆，替换默认安装图片；中文改用微软雅黑 UI，并启用高分屏识别。
- 选择安装位置后，同一页立即显示带 `pet-with-you` 的实际完整路径，安装时创建该目录；不重复嵌套同名文件夹。
- 普通快捷方式改用 EXE 内嵌图标，安装时刷新桌面、开始菜单中指向本次安装的普通桌宠快捷方式图标，保留启动参数；不更改 Codex withu 的专用图标。
- Hooks 指引和审阅按钮持续可见，当前连接状态加粗；点击连接／检查后显示检查中、完成时间和短暂高亮，防止旧后台检查覆盖新结果。

## 说明

支持 Windows 10/11 x64。安装包目前未签名，Windows 可能显示未知发布者提示；本页附 `SHA256SUMS.txt` 和 `INSTALL.txt`。其他自定义目录内的快捷方式或任务栏固定图标如仍保留旧缓存，可在设置中重新创建并固定。

GPT 任务反馈依赖客户端本机记录及 Hooks；兼容运行程序和信任配置按设置内指引完成。聊天与碎碎念使用所选 API 服务，会产生相应模型用量。

代码采用 MIT；上游代码、角色和动画来源见仓库的来源与致谢，角色素材保留原作非商业使用限制。安装包不附带第三方字体。
