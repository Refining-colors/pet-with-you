# pet-with-you 0.1.0-alpha.7.1.6

右键桌宠的设置入口现为 **桌宠控制台**，使用独立浅蓝色按钮背景，方便找到。

## 更新内容

- 纯桌宠模式隐藏 GPT 专用窗口选项；连接模式中统一显示“在GPT置顶，其余全屏隐藏”。
- 新增“关闭甩动”和“关闭边缘回弹”两个独立开关，默认关闭，可分别控制松手惯性和碰到屏幕边缘的反弹。
- Hooks 连接页提供截图和逐步授权指引，普通操作不再直接弹出备用终端；图标未出现时提示切换对话，仍没有时在任务结束后重启客户端。
- 授权后重新检查立即获取新状态，避免旧缓存覆盖新结果；区分配置已写入、等待授权和实际收到任务事件。
- 修正备用终端的交互输入环境，保留纯桌宠、自有 API 与现有设置兼容。
- 同步安装、使用和排错手册；保留全部 106 段原始动画及运行环境。

## 下载与升级

下载 **pet-with-you-0.1.0-alpha.7.1.6-x64-setup.exe**。普通用户不需要下载 Source code，也无需另装 Node.js、Git 或 Codex CLI 来使用纯桌宠。

已有用户先退出桌宠，再运行新版安装程序直接覆盖升级，无需卸载。安装目录和用户数据分开，保留已有设置；桌面与开始菜单快捷方式继续使用。Codex 联动可使用客户端自带的兼容运行程序，具体见连接指引。

这是 Windows 10/11 x64 预览版，安装程序尚未签名。SHA256SUMS.txt 用于校验文件完整性，INSTALL.txt 提供简明安装说明。Hooks 授权图标的刷新时机由客户端控制，本版不保证能强制使其立即出现。

代码采用 MIT；角色动画保留原作许可与署名要求。详情见仓库来源与致谢。
