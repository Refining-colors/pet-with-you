Windows x64 安装预览更新。普通用户下载 **pet-with-you-0.1.0-alpha.7-x64-setup.exe**，无需下载源码或另装 Node.js。

### 安装目录检测

- 保留自定义目录安装，不限定磁盘；新增安装前实际写入检测。
- 检查目标主目录、资源子目录，以及已有程序、图标和动画文件是否可写。
- 遇到权限拒绝、只读文件或文件占用，提前停止并显示 Windows 错误码及路径，尽量保存 `%TEMP%\pet-with-you-install-check.txt`。
- 检测失败时不进入旧版本卸载或文件覆盖阶段；不自动修改目录权限、不强制提权。
- 新增自定义中文/空格路径、只读图标、占用动画和拒绝写入的回归验收。

本次针对用户反馈的“不能打开要写入的文件”加强诊断与安装保护；截图不足以确认对方电脑的具体原因，不能保证解除安全软件或目录权限限制。报错时请勿选“忽略”，按错误码处理后重试。

继承 alpha.5 的全部功能：106 段动画、可选自有 API 与 Codex 联动、四种互斥窗口模式、单击托盘临时显示 8 秒。

### 安装与升级

选择当前用户有写入权限的独立目录。已有用户先退出桌宠，再安装到原目录；用户设置和密钥独立保存。当前为未签名预览版，尚无自动更新。

下载附带 `INSTALL.txt` 和 `SHA256SUMS.txt`。安装包不包含个人配置、密钥、日志、第三方字体或视频实验素材。
