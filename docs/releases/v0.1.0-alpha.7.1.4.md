# pet-with-you 0.1.0-alpha.7.1.4

现在可以直接右键桌宠调整大小，无需反复打开设置。本次同时修复右键时角色短暂闪现的残影，并缩小安装包。

## 下载安装

下载本页 Assets 中的 **pet-with-you-0.1.0-alpha.7.1.4-x64-setup.exe**，双击安装。纯桌宠无需另装 Node.js、Git 或 Codex CLI。`Source code (zip)` 是源码，不是安装程序。

旧版用户先从托盘退出桌宠，再运行新版安装程序，沿用原目录即可覆盖升级，无需卸载；保留个人设置、密钥和位置。

## 本次更新

- 右键桌宠新增“调整大小”子菜单，提供同步滑条与数值输入，支持 180–900 px，实时预览、自动保存，重启后仍生效。
- 新增“恢复初始大小”，一键恢复 462 px。菜单调节与设置页同步，保留其他未保存的设置草稿。
- 双击普通快捷方式只显示桌宠，不再自动打开设置；兼容旧快捷方式，再次启动会显示已有桌宠。
- 修复右键菜单开启时角色旁边瞬间出现残影的问题；菜单开关不再移动角色画面与系统窗口，透明区域保持点击穿透。
- 改用完整安装包的固实无损压缩，本机对比由 151.9 MiB 降至 143.6 MiB，约减少 5.5%。保留全部 106 段原始动画、图片、语言与运行组件；安装后的占用基本不变，最终下载大小以本页资产为准。

## 说明

支持 Windows 10/11 x64。安装包目前未签名，Windows 可能显示未知发布者；本页附 `SHA256SUMS.txt` 和 `INSTALL.txt`。当前通过下载新版完整安装包升级，尚无自动更新。

GPT 任务反馈依赖客户端本机记录及 Hooks，按设置指引完成连接与信任配置。聊天与碎碎念使用所选 API 服务，会产生相应模型用量。

代码采用 MIT；上游代码、角色和动画来源见[来源与致谢](https://github.com/Refining-colors/pet-with-you/blob/main/ATTRIBUTION.md)，角色素材保留原作非商业使用限制。安装包不附带第三方字体。
