# 一个文件分享桌宠设置

从 `0.1.0-alpha.2` 开始，普通桌宠设置统一保存在用户数据目录的 **settings.json**。设置页最下方的“保存修改并定位设置文件”会先应用当前修改，再在资源管理器中选中这个文件。

## 怎样分享和覆盖

1. 发送者点击设置底部的定位按钮，然后退出桌宠，复制 `settings.json` 给对方。
2. 接收者先启动一次自己的桌宠，用同一按钮找到自己的文件，然后退出桌宠。
3. 备份自己的 `settings.json`，用收到的同名文件覆盖，再启动桌宠。
4. 填写自己的 API 或额度查询密钥。需要 GPT 联动时，在本机重新配置联动快捷方式和账户来源。

不要在桌宠仍运行时覆盖文件，内存中的未保存设置可能覆盖你的修改。只接收自己信任的配置；文件包含服务地址、自定义提示词和自动碎碎念等行为设置，分享前可检查这些内容。

## 文件里有什么

运行模式、窗口与启停开关、动作权重、宠物尺寸和位置、反馈与额度气泡、自动碎碎念、模块排序、字体选择、自有 API 的地址和模型、额度查询字段以及两种命名配置列表都在此文件中。

JSON 最外层有 `schemaVersion: 1`，各模块在 `sections` 下。一般不需要手工编辑。格式损坏或版本不支持时，程序会报错并保留原文件，不会直接以默认值覆盖。

## 哪些内容留在本机

| 内容 | 原因 |
| --- | --- |
| `credentials.local.json` | 保存系统加密的实际密钥；共享设置只保存随机引用，不含密钥或密文 |
| `client-launcher.local.json`、`startup-target.json`、`runtime-path.json` | 当前电脑的应用入口、运行程序与安装位置，不能照搬到别人电脑 |
| 登录账户、聊天记录、日志、连接令牌、显示缩放缓存 | 是私有数据或运行状态，不属于可分享的桌宠设置 |
| 自行导入的字体和额外角色素材 | 是资源文件，不自动嵌入设置；缺少导入字体时暂时回退宋体 |

共享配置中的密钥引用在别人的电脑上不能解锁你的密钥；更换服务地址也不能借用旧地址的密钥。收到配置后，地址与模型可以直接载入，实际密钥需要重新填写。不要分享整个用户数据文件夹。

## 从旧版升级

首次运行会将旧的 `preferences.json`、`main-config.json`、`appearance.json`、位置、托盘状态和服务配置等合并。迁移成功后，旧文件转入 `legacy-settings/` 作为本地回退备份；以后只读取 `settings.json`。

备份中可能有旧的加密密钥，不能分享。若旧设置损坏，程序会停止迁移，避免静默丢失原设置。暂不自动删除迁移备份。
