# 从零安装与配置 pet-with-you

这份手册面向第一次下载 GitHub 项目的人。当前为 **0.1.0-alpha.7 公开预览版**，普通用户推荐直接下载安装程序，无需购买开发工具，也不必安装 Git 或 Node.js。需要修改代码的用户可按第一至第四步安装源码版。

## 推荐：使用安装程序

打开 [0.1.0-alpha.7 下载页](https://github.com/Refining-colors/pet-with-you/releases/tag/v0.1.0-alpha.7)，在 **Assets** 中选择 **pet-with-you-0.1.0-alpha.7-x64-setup.exe**。不要把 `Source code (zip)` 当作安装包。下载后双击，选择安装目录，按需勾选“创建桌面快捷方式”。安装仅针对当前 Windows 用户，默认不需要管理员权限；自定义目录需对当前用户可写，建议使用独立文件夹，避免放进其他软件的受保护安装目录。安装完成后从开始菜单或桌面的 **pet-with-u** 启动，首次打开设置，默认纯桌宠。

安装版自带 Electron 与 Node.js 运行环境，日常动画、自有 API 和 Hooks 转发无需另装 Node.js。Codex 账户功能仍需兼容的 Codex 运行程序，详见第七步。安装包目前没有代码签名，Windows 可能显示发布者未验证；请核对下载来源，下载页的 `SHA256SUMS.txt` 提供安装程序校验值。安装包使用系统字体，不附带第三方字体；可在设置中选择或导入自己有权使用的字体。

遇到“不能打开要写入的文件”时不要选“忽略”；请按[安装写入错误排查](TROUBLESHOOTING.md#安装程序提示不能打开要写入的文件)处理。新版安装器会提前检测常见写入问题并提供系统错误码。

第一次正常打开设置时询问是否创建 `pet-with-u` 快捷方式，选择创建后可自选目录；安装时已经创建则可跳过。选择仅询问一次，以后仍能从基础设置创建。

升级可重新安装新版到相同目录，用户数据与安装目录分开保存。卸载会移除属于此安装的快捷方式和 Hooks，并保留用户设置与密钥；需要完全清除时按 [排错手册](TROUBLESHOOTING.md) 定位数据目录后自行处理。源码版与安装版正式启动会共用兼容数据目录，切换前先退出正在运行的桌宠。

以下第一至第四步针对源码版；安装版从第五步的功能配置继续即可。[打包与更新准备](PACKAGING.md)说明当前限制和验证办法。

项目基于 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 改造，角色动画来自原作。

## 先选你要用的功能

| 想要的功能 | 必须准备 | 不必准备 |
| --- | --- | --- |
| 桌宠动作、拖动、手动点播 | Windows；安装版自带环境，源码版需 Node.js 和 Electron 依赖 | Codex、API 密钥 |
| 自有 API 聊天和碎碎念 | 上一行 + 服务商 API 地址、模型名、密钥 | Codex CLI、Codex 登录 |
| 密钥或代理额度查询 | 服务商提供的查询接口和鉴权信息 | 聊天模型调用、MCP |
| Codex 本地任务反馈 | 含 Codex 功能的桌面客户端、本地会话记录；Hooks 可补充事件 | 不要求始终运行一个 CLI 聊天窗口 |
| Codex 账户额度、账户聊天、Hooks 审阅 | 兼容的 Codex 运行程序及相应登录/配置 | 如果客户端已有运行程序，不必再装一份 CLI |

“GPT连接设置”是桌宠的设置名称，目前针对本机 **Codex 工作任务**。它不是支持所有 GPT 产品的通用连接器；普通网页 ChatGPT 对话、其他厂商客户端及远程/云端任务不能保证有任务反馈。

## 第一步：安装前置软件（仅源码版）

1. 使用 Windows 10 或 11。本项目当前以 Windows 桌面环境验证，其他系统未支持；不同 CPU 架构的兼容性需要实际验证。
2. 打开 [Node.js 官方下载页](https://nodejs.org/en/download)，选择 Windows 的 LTS 安装程序，版本至少 22.12。安装时保留默认的 npm 和 PATH 选项。
3. 安装后关闭再重新打开终端。按 `Win + R`，输入 `cmd`，回车，依次输入：

   ```text
   node --version
   npm --version
   ```

   能显示版本号即可。如果提示“不是内部或外部命令”，先重开终端，必要时重新安装并勾选添加 PATH。

Electron 是桌宠的窗口运行环境，下一步会自动下载，无需另找 Electron 安装包。

## 第二步：下载并放好项目（仅源码版）

打开 [Refining-colors/pet-with-you](https://github.com/Refining-colors/pet-with-you)，点击绿色 **Code → Download ZIP**。下载后右键压缩包 → 全部解压，进入解压出来的 `pet-with-you-main` 目录。不需要 GitHub 账号或 Git；不要下载上游仓库代替本项目。

把解压后的项目放在准备长期使用的目录，例如自己的应用目录。确认目录里有 `package.json`、`Install-Pet.cmd`、`Start-Pet.cmd`、`assets`，而不是只下载了 README。

不要直接在压缩包内运行，不要放在会定期清空的临时目录。路径由启动脚本自动计算，支持包含空格的路径；用户数据与项目目录分开保存。

## 第三步：安装桌宠依赖（仅源码版）

1. 双击 `Install-Pet.cmd`。这是依赖安装入口；Node.js 需要先按第一步安装。
2. 看到 `[1/3]` 时正在下载依赖与 Electron，首次可能等待数分钟；`[2/3]` 为本机检查。最后按 `Y` 创建桌面快捷方式，或按 `N` 跳过，出现 `Ready` 表示安装成功。首次需要网络下载 npm/Electron 依赖。
3. 如果失败，保留窗口里的错误信息，见 [排错手册](TROUBLESHOOTING.md)。
4. 双击 `Check-Setup.cmd` 做环境检查。Codex 标为可选项，不影响纯桌宠。

习惯终端的用户可以在项目目录运行 `npm ci --include=dev`。这是安装项目依赖，不会自动安装或登录 Codex。

以后补建快捷方式可双击 `Create-Shortcut.cmd`。快捷方式自动记录当前源码目录、Node.js 路径与图标位置；项目或 Node.js 移动后应重新创建。自动安装可用 `Install-Pet.cmd --no-shortcut` 跳过快捷方式询问，或 `--shortcut` 创建。

普通快捷方式名为 `pet-with-u`，联合启动器名为 `Codex withu`；项目和 EXE 仍叫 `pet-with-you`。这些名称和最新启停方式已包含在 alpha.5 安装程序中；不要用旧 alpha.3 本地安装包覆盖新版。

## 第四步：先启动纯桌宠

双击 `Start-Pet.cmd`。第一次默认纯桌宠，之后沿用上次模式。右键桌宠或双击托盘图标可以打开设置。

第一次验收：能看到宠物；能拖动；右键能点播动作；关闭设置再重开后设置保留。**关闭设置窗口不等于退出桌宠**，退出请用右键菜单的“退出桌宠”。

普通设置关闭窗口时自动保存；输入错误时窗口会留下并提示，请修正后再关闭。

## 第五步：配置聊天与碎碎念（可选）

在 **基础设置 → 聊天与碎碎念 / 自有 API** 配置：

| 字段 | 填什么 | 示例（不能用于实际连接） |
| --- | --- | --- |
| 配置名称 | 自己容易区分的名字 | 我的日常聊天 |
| API 地址 | 服务商文档中的 OpenAI 兼容地址 | `https://api.example.com/v1` |
| 模型名 | 服务商实际开放的模型标识，逐字填写 | 服务商给出的模型 ID |
| API 密钥 | 服务商创建的密钥 | 在设置中填写，别放到聊天截图里 |

也支持完整的 `https://api.example.com/v1/chat/completions` 地址。普通网站首页和网页聊天地址通常不是 API 地址；本项目使用 Chat Completions 兼容接口。

关闭设置应用当前配置；要留存多组配置，填名称后点“保存到配置列表”。“载入”切换配置，“删除”删除列表中的那一组，“一键清除”清除当前配置但保留已存列表。API 密钥以掩码显示，不会因为显示星号就被清空。

回到桌宠，右键 → 聊天或碎碎念，发送一句简单的话。出现正文表示聊天链路可用。此步骤会调用你选择的服务，可能消耗 token 或费用。

自动碎碎念先保持关闭；确认手动可用后，再按 [使用手册](USER_GUIDE.md) 设置间隔、概率。连接 Codex 后仍可以选择自有 API。

## 第六步：配置密钥/代理额度查询（可选）

**聊天成功不代表额度接口也存在。** 请先从服务商获得查询地址和鉴权说明。

### CRS 示例

打开“设置密钥 / 代理查询”，填写：

1. 配置名称自行命名。
2. 查询地址填写 `https://crs.uuid.im/admin-next/api-stats`。
3. 密钥来源按实际情况选：手动密钥、自有 API 密钥、环境变量，或连接模式中的当前服务商/config 来源。
4. CRS 可使用监测信息格式；具体密钥和请求头以服务商要求为准。
5. 用设置内的查询按钮验证，成功后再保存到命名列表。

### 其他服务商

目前支持部分 **HTTPS JSON 查询接口**。需要知道返回值路径，例如响应 `{"data":{"balance":12.5}}` 对应 `data.balance`；再设置余额/已用百分比、单位和换算系数。

鉴权支持 `Authorization` 或 `x-api-key`，可控制 Bearer 前缀。接口不能把密钥放在网址参数里。普通 HTML 登录页、验证码、需要网页登录 Cookie 的查询站点，不是填网址就一定能读取。

“保存到配置列表”“载入”“删除”“一键清除”与自有 API 一致；密钥摘要仅显示开头 7 个字符。账户额度与密钥余额是不同来源，务必选对。

## 第七步：连接 Codex 桌面客户端（可选）

### 7.1 准备客户端和运行程序

先按 [官方桌面客户端说明](https://developers.openai.com/codex/app/) 安装并登录支持 Codex 的桌面客户端；[Windows 说明](https://developers.openai.com/codex/windows/)介绍 Windows 本机运行环境。产品名称和安装页面可能随官方更新变化。

桌宠优先使用：环境变量 `PET_CODEX_EXE` 指定的文件、设置中选过的运行程序、桌面客户端的常见附带目录，然后查找 PATH 中的程序和常见 npm 安装目录。

**并不是每个人都要额外下载安装 CLI。** 有兼容的 `codex.exe` 就可以复用。仅当自动查找失败时：

- 在桌宠设置里“选择 Codex 运行程序”，选择真实的 `codex.exe`，不要选择桌面客户端启动器 `ChatGPT.exe`。
- 或按照 [Codex CLI 官方安装说明](https://developers.openai.com/codex/cli/)安装。已经有 Node.js 的用户可在普通终端运行 `npm install -g @openai/codex`，再重新打开桌宠。下载方式以官方页面当前提供的 Windows 选项为准。

用 `codex --version` 检查 CLI 是否可运行。若该运行程序看不到你的账户，按官方登录流程完成登录；桌面客户端的所有安装渠道不一定共享同一个账户存储。

### 7.2 打开连接模式

1. 先打开并登录客户端。
2. 打开桌宠设置，开启“连接 GPT 客户端”。“GPT连接设置”会立刻出现在同一个设置窗口。
3. 首次提示选择桌宠聊天来源：GPT 当前账户/config 密钥，或自有 API。这个选择决定聊天请求走哪里，任务反馈仍可保持开启。
4. 在 GPT 连接页检查连接状态，按界面按钮安装/检查联动配置。

安装版直接从桌宠设置连接即可，不需要寻找以下脚本。以下三个入口仅用于源码版：

| 入口 | 行为 |
| --- | --- |
| `Start-Pet.cmd` | 启动宠物和设置，保留上次模式 |
| `Connect-Pet.cmd` | 打开连接设置；首次单独运行时可只开配置，不显示宠物 |
| `Start-And-Connect.cmd` | 启动宠物并准备连接配置 |

连接入口会把模式切到连接模式，并写入本项目 Hooks 配置。配置失败时看设置提示；启动命令本身成功不代表 Hooks 已获信任。

### 7.3 审阅 Hooks

Hooks 是客户端在提交消息、使用工具、完成回合等时刻调用本机脚本的机制，不是持续向 AI 发问。桌宠安装器会合并到 Codex 的 `hooks.json`，更改前留备份，保留其他 Hooks。

1. 在桌宠里点击审阅 Hooks；源码用户也可双击 `Review-Hooks.cmd`。
2. 在出现的 **Codex 交互终端输入框**输入 `/hooks`，不是在 PowerShell 提示符里直接执行 `/hooks`。
3. 检查项目目录中的 `hook.cjs`，按提示信任/启用本项目命令。不要顺手信任不认识的其他命令。
4. 回到桌宠重新检查。首次配置或路径变化后，如当前任务未加载新配置，可新开一个本地任务验证。

`TERM=dumb` 是终端显示能力警告，不代表连接成功。新的审阅入口已设置终端类型，并在结束后保留窗口；如果仍失败，记录具体提示，见排错手册。

官方说明：[Hooks 文档](https://developers.openai.com/codex/hooks/)。非受管理的 Hooks 需要审阅并信任；不能由桌宠替你伪造信任。

### 7.4 实际验收

在客户端新建或继续一个本地 Codex 任务，观察思考、执行工具或完成反馈。设置中的本地会话读取状态、最近 Hook 事件分别代表不同来源；单一“配置成功”不能证明所有事件都已到达。

多任务会显示已观测数量和任务卡。任务记录只用于本机读取状态/标题，不需要持续调用 MCP，也不产生额外模型 token。详情与限制见使用手册。

账户额度通过兼容运行程序的 `account/rateLimits/read` 查询；[官方 app-server 文档](https://developers.openai.com/codex/app-server/)说明此接口。登录账户无对应窗口或接口不可用时，会明确提示而不会编造额度。中转密钥用户可直接配置自己的查询 URL，无需为了读 GPT 账户而强制改网络。

## 第八步：自启动、更新与卸载

### 自启动

在设置中开启“开机自启动”，会创建当前用户 Startup 目录的快捷方式，一般无需管理员。登录时读取设置，只启动一次，不运行持续监听。

当前版本不再提供“随 GPT 客户端启动”开关。首次开启连接模式会询问是否创建 **Codex withu**；也可在 **GPT连接设置 → 创建联动启动器** 中操作。选择自动发现的系统应用，或客户端原始 EXE／快捷方式，然后自选保存目录。双击生成的图标同时打开客户端与桌宠，保留桌宠上次的模式。需要任务栏入口时，手动固定这个新启动器。原版图标、协议链接不会触发桌宠；无需配置进程审计、计划任务或管理员权限。

“随 GPT 客户端关闭”可单独开启；未勾选时客户端退出不要求桌宠退出。窗口隐藏或检测出错不会直接视为退出，退出前还会保存并复核最新设置。

历史兼容入口仍叫 `DSH Pet Companion.lnk`，这是本项目入口，避免升级重复创建。开关默认关闭。

### 更新 / 换目录

安装版：退出桌宠、备份个人数据，再运行新版安装程序，选择相同安装目录。当前没有自动更新功能。

源码版：退出桌宠，备份个人数据，再更新项目文件并重新运行 `Install-Pet.cmd`。不要在运行过程中删除项目文件或依赖。移动目录后从新位置启动，重新连接刷新 Hooks 路径；自启动入口也需要更新。

### 卸载

安装版先退出桌宠，再从 Windows“设置 → 应用”卸载。默认保留个人数据；需要彻底清除时参考下面第四步。

源码版按以下步骤处理：

1. 在设置中关闭开机自启动，再退出桌宠；删除不再使用的 `Codex withu` 和普通桌宠快捷方式。
2. 在项目目录运行 `node uninstall-hooks.cjs`，移除当前项目路径的 Hooks。
3. 删除项目目录。如果以前移动过目录，检查 `/hooks` 是否仍有旧路径的本项目条目，只移除确认无用的条目。
4. 如需彻底清除本机设置，再自行删除 `%APPDATA%\DSH Pet Companion`。这会删除密钥配置、聊天记忆、位置与字体设置，不能靠重新下载项目恢复。

## 让 AI 帮你配置

安装版用户可把这段话交给 AI：

> 请根据 pet-with-you 仓库的 docs/INSTALL.md 和 docs/USER_GUIDE.md，指导我下载当前 Windows x64 Release 的 EXE 并配置【纯桌宠 / 自有 API / Codex 联动】。我使用安装版，不需要源码安装步骤。不要读取或输出我的密钥，不要自动发起付费聊天。

源码用户可把以下文字交给能读取本地项目的 AI，然后由你在设置里填写真实密钥：

> 请先阅读项目的 AGENTS.md、docs/INSTALL.md 和 docs/TROUBLESHOOTING.md。运行环境检查，确认 Node.js 与 Electron 可用，先启动纯桌宠并验证动画。我要使用的功能是【纯桌宠 / 自有 API / Codex 联动】。不要读取或输出我的密钥、auth.json 和 connection.json，不要自动开始付费聊天，不要跳过 Hooks 审阅。遇到缺失信息请给我具体字段和填写位置；普通设置关闭窗口自动保存，命名配置需明确保存。
