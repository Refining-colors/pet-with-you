# 源码工作区与 Git 入门

## 三类内容分开放

`pet-with-you` 是用于开发、版本管理及准备上传 GitHub 的源码目录。维护者之前使用的 `dsh-pet-companion` 可暂时继续用于日常运行和已有媒体工作；后续改代码统一在新仓库中完成，避免两边各改一份。其他用户只需自己的一个源码目录，不需要照着创建旧目录。

| 内容 | 放在哪里 | 是否提交 Git |
| --- | --- | --- |
| 程序、启动入口、默认配置、必要角色资源 | 仓库源码与 `assets/` | 是 |
| 首页、手册、已挑选且脱敏的配图 | `README.md`、`docs/` | 是 |
| 开发预览的设置与独立 Codex 目录 | `.local/` | 否 |
| 日常密钥、位置、个人字体、聊天记录 | Windows 用户数据目录 | 否 |
| 安装的依赖、下载缓存 | `node_modules/`、`.npm-cache/` | 否 |
| 录屏、参考视频、临时动画、测试截图 | `media-output/`、`qa-output/` | 否 |
| 安装包与临时发布文件 | `dist/`、`release/` | 否，成品通过 Releases 单独发布 |

已有参考视频和旧演示保留在原工作目录；新仓库没有复制它们。正式媒体工作可以在仓库外另建文件夹。只有确定要用于首页的演示图片才放入 `docs/images/`，并检查人物/字体授权和信息脱敏。

## 初始设置从哪里来

仓库不附带某位用户的配置备份。首次启动时，由 `preferences.cjs`、`appearance.cjs` 和 `assets/config.jsonc` 等默认定义生成当前用户自己的配置。

| 功能 | 首次默认行为 |
| --- | --- |
| 运行模式 | 纯桌宠 |
| Codex 账户、API、查询密钥 | 不附带账户或密钥，需要用户自行配置 |
| 自动碎碎念 | 关闭，开启并配置服务后才会自动生成 |
| 回合结束自动查询 | 关闭 |
| 开机自启动、随客户端关闭 | 关闭 |
| Codex withu 联合启动器 | 首次连接询问是否创建，不默认生成 |
| 自主跑动 | 允许，可在设置中禁止 |
| 窗口模式 | 普通显示；连接 GPT 后才显示 GPT 专用模式 |

日常数据保持在 `%APPDATA%\DSH Pet Companion`，保留这个兼容目录名是为了升级后继续使用旧设置。移动源码目录不会自动搬走个人数据；启动路径由当前目录和系统信息确定。

## 开发时怎么启动

首次在仓库目录执行：

```powershell
npm ci --cache .npm-cache
npm start
```

也可双击 `Dev-Pet.cmd`。开发窗口使用 `.local/dev-data`，并将 Codex 主目录隔离到 `.local/dev-codex`。它可以与日常桌宠并存，首次是全新配置。不要在开发预览里配置真实账户来验证模拟流程；如主动配置自有 API，产生的请求依然可能收费。

开发预览禁止修改系统启动项、创建真实客户端联动入口或随客户端关闭。不要用 `Start-Pet.cmd` 代替开发预览，它是面向正常使用的入口，会读取日常配置。正式运行入口移动后，开机启动和 Hooks 需要从新位置重新配置；仅建立新源码目录并不代表日常安装已迁移。

完整检查：

```powershell
npm test
npm run test:ui
npm run check:docs
```

自动界面测试与录制用临时桌宠数据和临时 Codex 主目录，使用演示数据；退出后清理临时个人数据。

## Git、GitHub 分别做什么

- Git 在本机记录源码历史，可以查看修改、做提交、比较版本。
- GitHub 是远程仓库；本机提交不会自动上传，只有推送才上传。
- `.gitignore` 让运行数据和媒体产物不进入待提交列表，但不能替代人工检查。
- 不要在 GitHub 网页额外生成第二份 README。本仓库已有 README、MIT 代码许可证和来源说明；角色与字体按各自条款处理。

日常操作可以使用编辑器的 Git 界面，也可以在本目录运行：

```powershell
git status
git diff
git add <本次修改的文件>
git diff --cached
git commit -m "说明这次解决的问题"
```

尖括号内容需要替换为实际文件。提交前确认没有密钥、私人设置和临时媒体；不要把 `.gitignore` 当作加密保护。Git 默认不会管理个人运行配置的历史。

准备对外发布并确认许可后，首次推送命令为：

```powershell
git push -u origin main
```

当前远程为 [Refining-colors/pet-with-you](https://github.com/Refining-colors/pet-with-you)。浏览器登录不等于本机 Git 已获推送权限；首次推送可能由凭据管理器提示登录。HTTPS 能访问时无需先配置 SSH；不要将令牌写进远程地址、源码或截图。
