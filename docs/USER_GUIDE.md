# pet-with-you 使用手册

全部动作和对应触发方式可查看 [动画与表情图鉴](ANIMATIONS.md)。

第一次运行先看 [从零安装与配置](INSTALL.md)，报错看 [排错手册](TROUBLESHOOTING.md)。本项目基于 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 改造，保留原角色与动画。

## 安装与启动

在“基础设置”选项卡底部，点击“选择目录并创建快捷方式”，选择桌面或其他文件夹，即可创建名为 `pet-with-u`、带桌宠图标的启动入口。双击快捷方式会启动当前版本并打开设置；纯桌宠与连接模式均可使用，不依赖 GPT 联动入口。同名文件不会被覆盖，新快捷方式会另加编号。

首次正常启动并打开设置时，会弹出“是否创建 pet-with-u 启动快捷方式”。选择创建后使用同一个目录选择流程；安装向导已创建过时可选“暂不创建”。跳过或取消目录选择后不重复询问，仍可在基础设置中手动创建；创建失败会提示并记录错误，下次打开设置可重试。旧用户首次运行包含此功能的新版也会询问一次。开机／GPT 联动的后台启动以及隔离开发预览不主动弹窗；后台启动后手动打开设置时才询问。现存 alpha.3 安装包暂未包含此功能。

安装版快捷方式指向当前 EXE；源码版指向当前源码启动入口，移动目录后需重新创建。开发预览创建的入口名为“pet-with-u 开发预览”，继续使用独立预览设置，不会切换到日常配置。取消选目录不会生成文件；如创建失败，可换到有写入权限的个人目录。

双击 `Start-Pet.cmd` 启动桌宠和设置，使用上次模式；首次默认纯桌宠。`Connect-Pet.cmd` 侧重连接配置，`Start-And-Connect.cmd` 启动并准备连接。`launcher.vbs` 可用于无黑框快捷方式，参数 `start`、`connect`、`both` 对应三个入口。

右键宠物打开动作、聊天、碎碎念、查询和窗口菜单；单击托盘立即显示宠物并临时置顶 8 秒（包括被全屏规则或手动隐藏时），随后恢复原窗口规则；双击托盘打开控制台。关闭设置仅保存并关窗口，退出桌宠使用菜单中的退出。

托盘“关于 pet-with-you”直接用默认浏览器打开本项目 GitHub 仓库；来源与致谢在设置底部及仓库文档中保留。正常安装版的窗口、托盘与快捷方式不带“开发预览”标记。

## 两种模式与设置保存

| 功能 | 纯桌宠 | 连接 GPT 客户端 |
| --- | --- | --- |
| 动画、点播、拖动、字体和尺寸 | 可用 | 可用 |
| 自有 API 聊天、碎碎念 | 可用 | 可用，可选服务来源 |
| 密钥/代理额度查询 | 可用 | 可用 |
| 本地 Codex 任务反馈 | 停止读取 | 依可用事件显示 |
| Codex 账户额度和账户聊天 | 关闭 | 需兼容运行程序及有效登录 |
| 联动启动与随客户端关闭 | 联动启动器保留纯桌宠模式，不随客户端关闭 | 可创建联动启动器，随关闭单独设置 |

打开连接模式后，同一个窗口新增“GPT连接设置”选项卡；关掉模式后隐藏，回到基础设置。首次连接选择聊天与碎碎念用当前账户/config 或自有 API，之后可以修改。

普通字段在**关闭设置时自动保存**，包括勾选、字体、尺寸、时间、API 和查询当前配置；部分即时开关/模块顺序会立即保存。切换选项卡不丢草稿，输入无效或写入失败时窗口保留并提示。正常退出桌宠也先保存设置。

命名配置的“保存到配置列表、载入、删除、一键清除”是明确操作，不代替普通设置的自动保存。清除当前配置保留命名副本；删除列表项也不自动清空正在使用的配置。

## 设置模块排序

同一选项卡中按住“拖动排序”并移动，松开后保存；靠近上下边缘会滚动，按 Esc 取消。手柄保持普通指针。也可用 Tab 聚焦手柄，再按上下方向键移动。不能跨选项卡拖动模块。

## 日常动画与手动点播

现有 106 段动画中，80 段属于日常分类，其他属于待机、转向、移动、点击、拖动、额度、碎碎念和任务事件。

日常播放按分类权重抽取，分类内轮换并避开近期动作；不是把所有 106 段完全等概率混播。因此某些任务/额度动作在纯日常状态不会出现。右键动作菜单可以点播，包括“吃什么”“玩耍”和事件动作。

“动作 → 移动（原地播放）”只播放动作，不改变位置；“动作 → 跑动（实际移动）”提供奔跑、螃蟹走路和漂浮前进，带动桌宠移动。手动跑动不受“禁止跑动”限制；贴边时尝试向另一侧移动，两侧都没有足够空间时只播放动画。拖动或点播其他动作可以中断跑动。

手动点播和拖动优先于任务动画，结束后恢复当前任务或日常动作；任务进行中优先表达任务状态。同状态更新不让视频反复从头播放。点击回应和碎碎念分别轮换，尽量避免一轮内重复。

## 大小、字体、移动和窗口

普通设置集中保存在 `settings.json`，设置页最下方可定位。分享与覆盖步骤见 [统一设置文件说明](SETTINGS.md)；密钥、登录与本机启动路径不随该文件分享。

- 尺寸同时提供 **180–900** 的滑条和数值，双向同步；应用后保留位置。
- 气泡字体可分别设置“额度查询”与“基础反馈 / 聊天 / 碎碎念”，支持系统字体、导入 TTF/OTF。额度默认宋体，基础反馈保留原有风格，GPT 任务卡标题用原生风格字体。
- 语气结尾的 `~` 用单独字形修正视觉位置，复制出来的文本不变。字体是否允许分享应单独确认，个人导入字体不会自动变成项目素材。
- “禁止跑动”停止自主位移，手动跑动、拖动、抛掷和吸附仍可用；原地播放与实际跑动在动作菜单中分别选择。
- 设置和右键窗口菜单共用四种互斥模式，只能选择一个。旧设置升级时自动合并，不会同时勾选多项。

| 窗口模式 | 实际行为 |
| --- | --- |
| 普通显示 | 不置顶、不自动隐藏 |
| 始终置顶 | 保持置顶，不因全屏自动隐藏 |
| 全屏隐藏 | 平时置顶，任何应用全屏时隐藏所在屏幕的宠物 |
| GPT置顶，其余全屏隐藏 | 仅 Codex / ChatGPT 桌面应用位于前台时置顶；其他普通窗口下不置顶，其他应用全屏时隐藏所在屏幕的宠物 |

浏览器中的 GPT 网页不属于客户端例外。单击托盘的临时显示不改写已保存模式；修改模式或主动隐藏会立即结束临时显示。

客户端最小化后恢复、关闭后重新打开时，桌宠会重新检查实际窗口层级，按所选模式恢复显示。检测有短暂延迟，通常在下一次窗口检查后完成；不会抢走输入焦点。手动隐藏仍需单击托盘或选择显示宠物解除。此修复尚未包含在 alpha.7 安装包中。

- 吸附目标包括屏幕底部、任务栏上方及桌面客户端窗口下沿，靠近约 36 个界面像素时吸附，拖动可脱离。动画画布留在边界上方，静息脚部略悬空。客户端最小化/消失时解除对应吸附；浏览器中的 GPT 网页不属于客户端窗口目标。
- 位置按屏幕坐标保存，切换模式、重建窗口和重启尽量恢复；显示器移除后调整回可用屏幕。

托盘菜单字体为 11px，随 Windows 显示缩放变化；按钮直接显示。隐藏托盘后，可右键宠物“显示托盘图标”找回。

## 聊天、自有 API 与碎碎念

### 聊天服务和配置列表

纯桌宠固定使用自有 API；连接模式可选自有 API 或 GPT 当前账户/config 配置。支持 OpenAI 兼容 Chat Completions，包括符合校验要求的本机 HTTP 服务。选择聊天来源不改变任务反馈的来源。

配置从上到下为名称、API 地址、模型、密钥和操作按钮。保存列表显示地址/模型等摘要，不只有名字。密钥框保留星号掩码，未输入新值时继续使用原密钥。具体字段见安装手册。

聊天可携带配置的最近历史轮数，历史可能保存在本机 `memory.json`；它与下面仅保留本次运行的碎碎念记录不同。

### 手动与自动碎碎念

右键点击碎碎念后立即显示“碎碎念中……”。手动默认边生成边显示；若服务不支持流式，可在设置中关闭。自动碎碎念生成完成后显示，减少干扰。远端排队、网络和模型首字延迟无法只靠界面消除。

“聊天与碎碎念”内的碎碎念区域和独立自动碎碎念模块相互同步：

| 设置 | 行为 |
| --- | --- |
| 自动碎碎念 | 按宠物开启，默认关闭 |
| 间隔 | 60–86400 秒，启动后先等完整间隔 |
| 概率 | 0–100%，默认 50%；每次到间隔才进行一次概率判断 |
| 忙碌时 | 任务、拖动、点播、聊天、已有气泡或正在阅读时跳过 |
| 未命中/被跳过 | 不生成内容，不消耗模型用量，不积攒补发 |

一次启动到退出之间，每只宠物保留碎碎念记录；切换模式或重建窗口不清空。最近 20 条用于避免重复提示，完全相同或只改标点/空格的句子会被拦截，近义改写仍依赖模型。重复内容不自动重试，也不额外预生成。

### 回复气泡

正文可以选中后 Ctrl+C，右上角小叉关闭，没有额外复制按钮。支持：

| 停留方式 | 含义 |
| --- | --- |
| 自定义时长 | 1–3600 秒 |
| 下一次信息前不消失 | 新任务反馈或查询出现时清除旧回复 |
| 永久 | 保留最新回复，任务反馈暂时优先，结束后恢复 |

“永久”是本次运行内持续保留，**不表示退出后永久存档**。新回复替换旧回复，手动关闭清除；模式切换和窗口重建可恢复本次进程中的保留回复，退出后清空。任务反馈与聊天不会叠成两块相互遮挡的气泡。

## 额度查询

### 查询来源

Codex 登录账户用量和 API 服务商余额是两回事。设置中可直接查询当前配置；宠物菜单也可查询。自有 API 密钥不能查询 ChatGPT 订阅额度，除非选择的是另一个明确支持的账户来源。

“设置密钥 / 代理查询”支持手动密钥、自有 API、环境变量，以及连接模式中的客户端/config 来源。保存、载入、删除、清除与 API 配置一致。来源型配置只保存来源，查询时取对应密钥；手动密钥加密保存，界面摘要最多显示开头 7 个字符。

通用接口为 HTTPS GET JSON，支持字段路径和单位换算；CRS 提供专用统计适配。更换查询地址需要重新输入手动密钥，请求不跟随重定向。聊天可用不保证服务商有余额接口。

### 账户卡片与时长

Codex 账户显示 5 小时和 1 周的用量/剩余比例、各窗口重置时间、可用重置次数及更新时间。没返回的字段显示“未提供”；更新时间是最近一次成功获取数据的本机时间，缓存命中不会伪装成刚更新。

**GPT连接设置 → 额度查询气泡**：设置 1–3600 秒停留时间（默认 10 秒）或保持到手动关闭。查询中不计时，悬停和选择文字时暂停关闭。右上角关闭后，迟到结果不重新弹出。短内容不出现滚动条，长内容超过高度上限时正文才滚动。

### 自动查询触发规则

“每回合结束后自动查询并显示额度”默认关闭。新版没有启动即查询或每隔一段时间自行弹出额度的逻辑。

开启后，仅在连接模式下收到新回合结束、该宠物启用额度气泡、且未关闭事件响应时查询。连接前的历史完成不算新回合；多只宠物/同期完成共享查询。其他任务或交互尚在进行时暂缓，空闲后显示最新结果；新任务开始收起自动额度。手动查询优先。额度请求不调用聊天模型。

## Codex 任务反馈与多个任务

任务来源包括受信任的 Hooks 和本机兼容会话记录。仅恢复近期活动的本地任务，连续约 15 分钟没有可识别活动时清理可能过期的状态。读取不使用模型、不持续调用 MCP。

基础动画一次表达一种状态，优先级为：**等待确认 → 工具出错 → 执行工具 → 思考 → 整理结果 → 完成**；同级优先最近更新。多任务基础文字第一行是“已知 N 个任务进行中”，第二行直接显示优先状态。

GPT 原生风格任务卡最多列出三个已观测任务，更多任务显示数量；识别到的真实标题可点击打开对话。小尺寸/长内容确实超出上限时允许正文滚动。两种反馈独立开关，同时开启时任务卡在基础反馈上方；仅任务卡不接管动画。

这是本项目绘制的任务卡，不能保证完整获得原生客户端的审批详情、云端/远程任务和全部状态。本地记录格式可能随客户端升级变化，任务数量仅代表已经观测到的任务。

### 演示或录屏

开启 **GPT连接设置 → 任务动画与通知 → 关闭事件响应**，会暂停任务动画、基础/原生风格反馈、通知和自动额度，清掉排队的自动额度结果。继续记录任务状态，取消后恢复正在进行的任务，不补播静默期间的完成提示。日常动作、聊天、碎碎念和手动查询仍可使用；录屏前如不需要自动碎碎念，也应把它单独关闭。

## 启动与退出联动

开机自启动和随客户端关闭默认关闭，随关闭只在连接模式生效。纯桌宠不会跟随 GPT 客户端退出。最新源码已移除“随 GPT 客户端启动”开关，改为可选的 `Codex withu` 联合启动器；现存 alpha.3 安装包待下次统一更新。

首次开启连接模式，在聊天服务选择后会询问是否创建启动器。选择创建后，先选系统发现的客户端或原始 EXE／快捷方式，再选保存目录；选择“暂不创建”或取消创建后不反复询问。创建失败保留重试机会。以后可在 **GPT连接设置 → 客户端启动与退出 → 创建联动启动器** 随时创建。

启动器名为 `Codex withu`，使用 Codex 图标与吃饭小女仆的组合图，与普通桌宠入口区分。同名文件不会被覆盖，新文件另加编号。每次双击都会打开所选客户端和桌宠，不需要额外开关，不改变桌宠保存的运行模式；原版客户端入口不受影响。要使用任务栏入口，可手动固定新启动器。所有联动启动器使用本机最后一次保存的客户端目标，换目标会影响此前创建的入口；移动源码或安装目录后需重新创建。

开机自启动使用当前用户 Startup 快捷方式，只在登录时读取设置并启动一次，一般无需管理员，与联合启动器独立。

随客户端关闭由正在运行的桌宠检测，与是否使用联动入口无关。只有在连接模式、勾选随关闭，并确认客户端运行过之后，连续四次检测到所有已识别客户端都已退出，才会保存设置、复核开关并退出桌宠。正常约需数秒；最小化、隐藏窗口和检测失败不会直接触发退出。若另一个已识别的 Codex／ChatGPT 客户端仍在运行，桌宠会继续保留。

启动器自身不常驻；桌宠运行期间仍有窗口检测，用于全屏隐藏、吸附及随客户端关闭。退出桌宠后，这个检测也结束，不能再负责唤起桌宠。若在客户端运行期间手动退出桌宠，可以再次使用联合启动器打开桌宠。

| 入口或开关 | 作用 |
| --- | --- |
| `pet-with-u` | 直接打开桌宠及设置，不负责启动 GPT |
| `Codex withu` | 同时打开客户端与桌宠，保留上次保存的模式 |
| GPT 原版图标／原有任务栏图标／协议链接 | 直接打开 GPT，不经过桌宠启动器 |
| 随 GPT 客户端关闭 | 桌宠运行期间生效，无需通过联动入口启动 GPT |
| 开机自启动 | 登录 Windows 时启动桌宠，独立于 GPT 启停开关 |

原生客户端内部宠物按钮启动本项目目前没有稳定公开入口，未提供该能力。

## 日志与隐私

最近错误可排序，错误日志可查看、导出、定位和清除。“忽略 GPT 账户信息读取超时”默认开启，避免不需要账户查询的中转用户反复受扰；不屏蔽其他 API、额度或任务错误。手动查询仍显示实际结果。

系统加密的密钥、聊天记忆和个人导入字体位于个人数据目录，不能随源码发布；换 Windows 用户需重填密钥。记录模型错误、网络失败时尽量只留分类信息，反馈前仍需检查隐私，详见 [数据与安全](../SECURITY.md)。

## 用量与媒体制作

动画、拖动、设置、任务状态、本地录制和动画提取不消耗模型 token。额度查询只是查询接口，服务商可能另有频率限制；聊天和实际生成的碎碎念会消耗所选服务用量。

自动演示与素材导出见 [媒体制作手册](MEDIA_GUIDE.md)，安装和更新见 [全流程配置手册](INSTALL.md)。
