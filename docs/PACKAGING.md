# 预览版打包、安装与更新准备

本次发布版本为 **0.1.0-alpha.7.1.6**。代码采用 MIT，安装包不附带第三方字体。原作代码许可和角色素材限制仍见 [来源与致谢](../ATTRIBUTION.md)。[公开下载页面](https://github.com/Refining-colors/pet-with-you/releases/tag/v0.1.0-alpha.7.1.6)提供 EXE、校验文件和简明安装说明。

`0.1.0-alpha.7.1.1` 修正目录页即时预览、欢迎／完成页角色图、高分屏字体和快捷方式图标刷新。

## 给使用者

- 目标系统：Windows 10/11 x64。安装程序包含运行环境，纯桌宠不需要额外安装 Node.js。
- 安装时可选目录和桌面快捷方式，选择父目录后自动补 `pet-with-you` 子文件夹，开始菜单入口会自动建立。欢迎页和完成页使用蓝毛小女仆品牌图；EXE、安装程序、快捷方式使用与托盘同源的角色图标。
- 安装仅针对当前用户，默认不提权。安装结束后从快捷方式启动；不会自动连接账户或调用模型。
- 预览包暂未签名，因此发布者验证和 SmartScreen 信誉尚未建立。
- 设置、密钥、位置仍在兼容的用户数据目录，与安装文件分开。卸载保留这些数据，移除属于此安装的桌面/开始菜单入口及连接 Hooks。
- 源码版与安装版会共用正式用户数据，切换前先退出当前桌宠。不要将日常配置复制进源码或安装包。
- 设置集中到 `settings.json`，旧文件迁入 `legacy-settings/` 作为本机回退备份。密钥文件和备份不能分享。
- `Codex withu` 使用系统应用 ID 或用户选择的原始入口，不写死 Store 版本目录。它同时启动客户端和桌宠后退出，保留桌宠模式；不需要“随启动”开关。独立 PNG／ICO 随安装程序打包。

## 本机构建

当前构建为 `0.1.0-alpha.7.1.6`，在已有尺寸调整、快捷方式和安装包优化基础上，新增突出显示的桌宠控制台入口、独立甩动/回弹开关、纯模式菜单修正及 Hooks 图示授权与重新检查。公开安装包由版本标签在 GitHub 构建并验收；本机构建用于日常测试，二者分别验证。以后打包前仍需同步版本号、锁文件、更新记录，并重新验证安装及快捷方式。

使用 Windows、Node.js 22.12+，在项目目录执行：

```powershell
npm ci
npm test
npm run test:ui
npm run check:docs
npm run audit:source
npm run dist:win
```

构建输出为 `dist/pet-with-you-0.1.0-alpha.7.1.6-x64-setup.exe`，另有 `dist/win-unpacked/` 便于检查。版本来自 `package.json` 与锁文件，后续修改必须同步。构建命令明确使用 `--publish never`，不会自行上传 GitHub。

公开发布使用 **Build Windows release** 工作流：检出指定版本标签，运行源码检查、依赖审计、打包内容审计，并在干净 Windows runner 上真实安装/卸载两次，验证桌面快捷方式两种选择、开始菜单图标、无外部 Node.js 启动与用户数据保留。全部通过后生成带 EXE、SHA-256 和安装说明的预发布草稿；维护者核对后发布。已公开 Release 不自动覆盖。

首次构建需要下载 Electron 和安装器工具，网络不可用时会失败；可以使用你信任的代理或镜像，不要关闭 TLS 校验。构建产物、缓存、QA 日志与用户数据均不提交 Git。

## 实际验证

```powershell
node scripts/verify-packaged.cjs
node scripts/audit-package.cjs
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify-installer.ps1
```

第一个检查使用临时数据目录，移除 PATH 中的 Node.js，验证打包后启动、默认纯桌宠、106 段动画、视频分段传输、屏幕缩放探测和 Hooks 元数据转发。

第三个检查会真实安装、覆盖升级和卸载，分别验证创建/不创建桌面快捷方式、开始菜单目标与图标、带空格的自定义安装路径及用户数据保留。它使用隔离的 Codex 目录；发现已有本项目安装或同名快捷方式会停止，应在干净 Windows 账户运行。发布工作流还会下载并校验已发布的 alpha.7 安装程序，再运行跨版本升级检查。图形安装向导的实际观感仍需人工验收。

源码快捷方式另有路径迁移测试，覆盖空格、中文和单引号。普通开发使用 `npm start` 的隔离预览，不要运行正式启动入口代替测试。

## 为后续更新保留的约定

固定 `appId`、可执行文件名和用户数据目录，便于新版覆盖安装；卸载器识别升级场景，避免升级时清除 Hooks。构建配置预留本项目 GitHub prerelease 发布源和版本元数据。

**目前尚未实现联网检查更新、自动下载或自动更新。** 当前升级方式是退出桌宠后重新运行新版安装程序。后续接入更新器时，需要补齐代码签名、更新包校验、旧配置迁移及失败恢复测试，不能仅因存在发布地址就声称支持自动更新。

无需先卸载旧版。安装器沿用已登记的安装位置；旧版自定义目录即使没有标准名称，也不会因新目录规则被迁到子目录。新安装则规范化到 `pet-with-you` 子目录。自动验收包含不传安装目录时读取旧位置、保留 Hooks、快捷方式与测试数据；在干净 Windows 账户中，可给 `scripts/verify-installer.ps1` 传入 `-PreviousInstaller <旧安装包路径>` 做跨版本检查。

## 安装包体积

当前采用 `nsis.differentialPackage: false`，让 `compression: 'maximum'` 对完整安装包生效。打包器默认的差分模式会强制非固实压缩、小字典和普通压缩级别，但本项目尚无差分下载更新器。此调整只减少下载包体积，不减少安装后的文件或降低运行质量；覆盖升级仍通过完整 EXE 完成。未来接入差分更新时需重新评估并测试该配置。

安装版保留完整 Electron 运行环境、所有语言资源、106 段原始 WebM、角色图片和许可文件。打包审计逐项比较原始与安装版动画的 SHA-256，防止遗漏或转码降质。使用更高的无损压缩，排除仅供仓库介绍使用的 `docs/images/` 截图和 GIF 图鉴；完整配图仍可在 GitHub 手册中查看，文字手册仍随包提供。不会要求用户另装运行环境或启动后再下载动画。

预览暂用 `asar: false`，使外部 PowerShell 与 Hooks 命令有真实资源路径；个人数据不在该目录。后续如改为 ASAR，需要同步处理这些外部调用路径，并重新验证安装与升级。

发布前状态与未验证项目见 [发布检查记录](RELEASE_CHECK.md)。
